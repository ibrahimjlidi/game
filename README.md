# game

Static gift website with a separate mini-game page.

## Deploy with Vercel

1. In the Vercel dashboard, choose **Add New Project** and import `ibrahimjlidi/game`.
2. Select **Other** as the framework preset.
3. Leave the build command empty and set the output directory to `.`.
4. Click **Deploy**.

The uploaded portrait is stored in the browser and is not included in this repository. Visitors will see the heart collectibles until they choose their own photo.
